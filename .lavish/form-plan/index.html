03

Three environments. One project.

FIELD arranges the experiment. FRAME composes linked outputs. LIVE adds explicit time and signals. Only FIELD is in the first build.

A visual object is a placement.

The photograph, the operation and the output each have an identity. Several placements can point at one output. A composition stays connected without copying or flattening its process.

Start with a small technical stack.

React + TypeScript for controls and the shared core. PixiJS / WebGL2 for the first rendering adapter. Tauri is a desktop candidate to test early. Add native code, Three.js or WebGPU when a measured requirement justifies them.

CREATIVE RISK

Repeating a cutout is not enough.

Judge exposure weighting, motion distribution, mask edges and negative space using real source material. Current drawings make no output-quality claim.

RENDERING RISK

Large images change the problem.

An 8192² half-float RGBA texture is 512 MiB. Tiling must account for displaced source regions as well as the exported image.

INTEGRATION RISK

Control first. Native textures later.

A TouchDesigner WebSocket bridge is the first practical route. Syphon, Spout and TouchEngine need native work, runtime checks and measured transfer costs.
