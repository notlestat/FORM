# FORM

Experimental creative environment by Corey Kavanagh.

This initial main branch establishes the repository and development workflow. The complete local AFTERIMAGE prototype is proposed on codex/painted-subject-mask for pull-request review.

The proposed build includes spatial studies, photographic exposures along editable trajectories, painted selections, portable project files and transparent PNG export. Native platform and latest painted-mask rendering checks remain open.

Implementation changes require review before merging to main.
