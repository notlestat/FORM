# FORM

An experimental creative environment by Corey Kavanagh. AFTERIMAGE is its first instrument for spatial image studies.

## Repository status

The default branch contains this overview, repository instructions, and Git ignore rules. It has no application source, dependency manifest, or runnable preview.

Application work is proposed on feature branches. The [pull request list](https://github.com/notlestat/FORM/pulls) contains the reviewable implementations and their setup instructions. Check a proposal's branch and changed files before following commands from it.

Proposed capabilities include image exposures along editable paths, painted selections, portable project files, and PNG export. A proposal does not establish that those capabilities are available from `main`. Native platform support and rendering acceptance remain separate checks.

## Review a proposal

1. Open the relevant pull request and read its scope and verification notes.
2. Check out its head branch in a separate local checkout.
3. Follow that branch's README to install dependencies and start its preview.
4. Review rendering, editing, export, and save/reopen behavior with suitable test media.
5. Record the result before deciding whether to merge.

Follow [AGENTS.md](AGENTS.md) for the development workflow. Implementation changes require review, and merging requires the owner's explicit approval.
